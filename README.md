# EmotionRecognition

This project implements a complete emotion recognition pipeline using deep learning. It includes data preprocessing, image augmentation, a Convolutional Neural Network (CNN) for emotion classification, model evaluation, and a real-time application that detects faces and predicts emotions from a webcam feed.

The project utilizes the FER2013 dataset and demonstrates the complete machine learning workflow, including preprocessing, model training, evaluation through classification reports and confusion matrices, and deployment in a live emotion recognition application.

For a detailed explanation of the project architecture, preprocessing pipeline, model design, training process, evaluation, and future improvements, please refer to the accompanying presentation.
